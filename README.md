# B站键盘快捷键油猴脚本
> Tampermonkey userscript：B站按住左右方向键后，按上下键调节播放器音量，适配B站SPA单页路由跳转。

## ✨ 功能简介
- b站网页更新之后长按加速居然不能上下键调整音量了，与豆包研究了一会做出了这个我看不懂的js代码，豆包大人神力
- 在B站视频播放页，**按住 ← / → 方向键**，再按 ↑ / ↓ 调整视频音量
- ↑ 音量 +0.1，↓ 音量 -0.1，音量范围 0 ~ 1

## 📦 安装方式
1. 浏览器安装油猴扩展（Tampermonkey）
2. 新建脚本，复制js全部代码粘贴进去，保存
3. 打开B站视频页面刷新即可使用
